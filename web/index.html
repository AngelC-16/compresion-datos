⚠ Esta página no se abre así. Necesita el servidor de Python para hacer los cálculos.
Ciérrela y, en la carpeta del proyecto, haga una de estas:
  • Doble clic en abrir_interfaz.bat
  • En una terminal: python app.py
  • En VS Code: abra la carpeta compresion-datos y presione F5 → «Interfaz visual (app.py)»
Se abrirá sola en http://127.0.0.1:8000. No cierre la ventana negra/terminal mientras la usa.
